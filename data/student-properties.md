# Льготная категория и бюджетность студента

Все сборки используют одну базу в `$XDG_DATA_HOME/Столовая/canteen.db`
(обычно `~/.local/share/Столовая/canteen.db`). База в корне проекта больше
не используется при запуске: две разные базы не должны перезаписывать
один и тот же годовой Excel-файл.

В таблице `students` начиная с версии схемы 7 есть два независимых поля:

| Поле | Значение |
| --- | --- |
| `benefit_category` | Одна категория из списка ниже; `NULL`, если ещё не указана |
| `is_budget` | `1` — бюджет, `0` — не бюджет (ВБ); `NULL`, если ещё не указано |

Категории из файла «лЬГОТЫ.xlsx» приведены к единому регистру и написанию скобок:

- Сироты КРС
- Сироты ССЗ
- Сироты (ПП)
- Многодетные (КРС)
- Многодетные КРС 18+
- Многодетные (ССЗ)
- Многодетные ССЗ 18+
- Многодетные (ПП)
- Инвалиды (КРС)
- Инвалиды ССЗ
- Инвалиды (ПП)
- Дети мобилизованных КРС
- Дети мобилизованных ССЗ
- КРС нельготная категория

Для бюджетных и небюджетных студентов используется общий список категорий.
Недопустимые значения отклоняет сама база через `CHECK`, в том числе при
редактировании в DB Browser for SQLite. Пустая строка не заменяет `NULL`.

Программа автоматически добавляет поля при открытии существующей базы.
У прежних студентов оба значения остаются `NULL`: сводная таблица Excel
не содержит поимённого распределения. Заполнить поля можно в базе.
Импорт прежнего формата «ФИО, группа, карточка» сохраняет эти значения.

С версии схемы 8 журнал `meals` сохраняет ФИО, группу, `benefit_category`
и `is_budget` на момент каждой выдачи. Изменение студента после выдачи
не меняет её льготную категорию и бюджетность в отчётах. У старых выдач
категория и бюджетность остаются неизвестными: программа не восстанавливает
их из нынешнего состояния студента.

Excel содержит лист «Категории за год», отдельные месячные листы для
завтраков и обедов за сентябрь–август и ежедневные поимённые листы.
Месячные листы включают все календарные дни, бюджетные и небюджетные
категории, неуказанные сведения, подытоги и «Дето/дни». Считаются только
фактические выдачи из журнала. Одна выдача одного вида питания за день —
один дето-день. Годовой столбец «Всего приёмов пищи» складывает завтраки и обеды.

В ежедневном листе категория и бюджетность указаны на момент выдачи.
Если сведения изменились между завтраком и обедом, студент показан двумя
строками, каждая со своим состоянием и временем. Прежние ФИО и группа,
как и раньше, показаны рядом с нынешними, с зачёркиванием и примечанием.
